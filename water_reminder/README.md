# 💧 مُذكِّر شرب الماء المدرسي

تطبيق أندرويد عربي بالكامل يعمل **دون إنترنت ودون خوادم**، يساعد الطلاب على شرب كمية كافية من الماء خلال اليوم الدراسي. تُحفظ جميع البيانات على جهاز الطالب فقط.

## ✨ المزايا

| الشاشة | ما تقدمه |
|---|---|
| الترحيب والتسجيل | الاسم، الصف، الجنس، العمر، الوزن، الطول، مع عرض فوري للاحتياج اليومي المحسوب |
| الرئيسية | حلقة تقدم دائرية متحركة، الكمية المشروبة مقابل الهدف، أزرار سريعة (+١٥٠، +٢٥٠، +٥٠٠ مل)، كمية مخصصة، تراجع، وسجل اليوم |
| الإحصائيات | سلسلة الأيام المتتالية، المتوسط، أفضل يوم، مخطط أسبوعي، خطة توزيع اليوم الدراسي، نصائح وأفضل الممارسات، وسجل الأيام السابقة |
| التذكير | تفعيل/إيقاف، فترة ذكية تلقائية أو مخصصة، اختيار نغمة التنبيه، وتجربة الإشعار |
| الإعدادات | تعديل البيانات، شرح طريقة الحساب، مسح السجل، وإعادة ضبط التطبيق |

## 🧮 طريقة حساب الاحتياج اليومي

يُحسب الهدف بمتوسط ثلاث طرق صحية معتمدة، ثم يُقرَّب لأقرب ٥٠ مل (بين ١٠٠٠ و٣٥٠٠ مل):

1. **طريقة هوليداي وسيغار (الوزن):** ١٠٠ مل/كغ لأول ١٠ كغ، ثم ٥٠ مل/كغ للعشرة التالية، ثم ٢٠ مل/كغ لما يزيد.
2. **مساحة سطح الجسم (معادلة موستيلر، الوزن والطول):** ١٥٠٠ مل لكل متر مربع.
3. **الكمية الكافية حسب العمر والجنس** (الهيئة الأوروبية لسلامة الغذاء والأكاديمية الوطنية الأمريكية)، ويُحتسب منها ٨٠٪ من المشروبات.

فترة التذكير التلقائية = ساعات اليقظة (١٤ ساعة) ÷ عدد أكواب ٢٠٠ مل اللازمة، بين ٣٠ و١٢٠ دقيقة.

> هذه تقديرات تثقيفية، ويُستشار الطبيب في الحالات الصحية الخاصة.

## 🚀 خطوات التشغيل والبناء

### ١) تجهيز البيئة (مرة واحدة)
1. ثبّت **Flutter** (الإصدار ٣٫٣٥ أو أحدث) من الموقع الرسمي، وأضِف مجلد `flutter/bin` إلى متغير المسار.
2. ثبّت **Android Studio** ومن داخله: حزمة تطوير أندرويد وأدوات سطر الأوامر.
3. اقبل التراخيص وتحقّق من الجاهزية:
   ```bash
   flutter doctor --android-licenses
   flutter doctor
   ```

### ٢) تنزيل المكتبات
```bash
cd water_reminder
flutter pub get
```

### ٣) التشغيل والتجربة على جهاز أو محاكٍ
1. فعّل «خيارات المطوّر» ثم «تصحيح أخطاء الناقل التسلسلي» في هاتفك وصِله بالحاسوب، أو شغّل محاكياً من Android Studio.
2. نفّذ:
   ```bash
   flutter devices
   flutter run
   ```
3. لتشغيل الاختبارات والتحليل:
   ```bash
   flutter test
   flutter analyze
   ```

### ٤) بناء ملف التثبيت النهائي
```bash
flutter build apk --release
```
ستجد الملف في:
```
build/app/outputs/flutter-apk/app-release.apk
```
لملفات أصغر حجماً حسب معالج الجهاز:
```bash
flutter build apk --release --split-per-abi
```

### ٥) التثبيت على الهاتف
انسخ الملف إلى الهاتف وافتحه (مع السماح بالتثبيت من مصادر غير معروفة)، أو:
```bash
flutter install
```

## 🔔 ملاحظات حول الإشعارات
- يطلب التطبيق إذن الإشعارات عند التسجيل (أندرويد ١٣ فأحدث).
- قد تؤخر أنظمة توفير البطارية التنبيهات بضع دقائق؛ يُنصح باستثناء التطبيق من «تحسين البطارية».
- تبقى التذكيرات مجدولة بعد إعادة تشغيل الهاتف.

## 🔐 التوقيع للتوزيع الرسمي
يُوقَّع إصدار البناء حالياً بمفتاح التصحيح لتسهيل التجربة. قبل النشر في المتجر أنشئ مفتاح توقيع خاصاً وعدّل قسم `release` في الملف `android/app/build.gradle.kts`.
